**Regras desta matriz**

- O destino (`/Users/wallyssonnunes/www/tessel-editor`) tem o código em movimento e **nenhum commit**; as colunas de destino foram preenchidas **lendo** `docs/features/README.md` (sha256 `e2247306bd871fd1…`, mtime 2026-11-05T02:07), `core-architecture.md`, `viewport.md`, `spark.md`, `project-creation.md`, `video-export.md`, `history.md`, `project-document.md` e amostras de `crates/core/src/content.rs` e `runtime/src/scene.js`. **Não executei nada do destino** e não editei a matriz dele.
- Códigos das colunas de destino: `P` = pendente/inexistente; `N/A` = não se aplica (justificado no inventário); `Parcial (Fxxx genérico)` = existe um mecanismo genérico do destino, mas **não** a paridade com esta feature; `V*`, `I*`, `P*`, `N/A*` = a letra que a **matriz do destino** declara, para aquela superfície (UI / CLI headless / Lib), na(s) feature(s) `Fxxx` citada(s) — `V` validado, `I` implementado sem validação completa — evidência do próprio destino, não reverificada aqui e **sem implicar paridade** com a origem além do que a coluna *Diferença* diz; `Parcial (… ) · destino declara X` junta o que a origem exige com o que o destino declara (X) para o mecanismo genérico.
- Um `ui op`/socket da janela **não** conta como fluxo visual completo; e `CLI headless` só conta como tal se a matriz do destino o declara headless.
- Estratégias: **reusar** (código/dados da origem usados como estão), **adaptar** (aproveitar com mudanças), **reimplementar** (reescrever no destino com a origem como oráculo), **não migrar** (com razão).
- Prioridade: essencial / seguinte / futuro / não migrar, definida pelos fluxos reais (ver [migration-sequence.md](migration-sequence.md)).
