# Publicação open source

Repositório ativo: https://github.com/journey-studios/tessel-editor

- Organização: journey-studios; visibilidade PUBLIC, conferida também sem autenticação.
- Licença do projeto: MIT; dependências mantêm suas próprias licenças/notices.
- As duas fotografias sem licença verificada foram substituídas por ilustrações
  procedurais originais, regeneráveis por scripts/generate-demo-assets.py.
- Um histórico sanitizado foi publicado em repositório novo na organização. Os blobs
  antigos das fotografias não estão no histórico alcançável e retornam 404 pela API
  pública do novo repositório. O histórico privado anterior permanece privado e arquivado.
- A varredura de 641 blobs históricos não encontrou correspondências nos padrões de
  credenciais examinados; isso não equivale a uma auditoria completa de segurança.
- O remote origin local aponta para journey-studios; private-history preserva o remoto
  anterior. As alterações pendentes de G foram preservadas byte a byte na mudança.

A publicação não declara a migração completa: o status por UI/CLI/lib continua na matriz
de features. O trabalho da base segue no PR draft #1 do repositório da organização.
