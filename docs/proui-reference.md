# Referência ProUI — Splice

- Demo de referência visual: https://pro-ui.dev/examples/video-editor
- A biblioteca, o inspetor e a timeline orientaram a composição do protótipo.
- A implementação é Rust + GPUI Kit; o kit comercial ProUI não é distribuído aqui.

## Mídia de demonstração

`assets/demo/highlands.png` e `assets/demo/coast.png` são ilustrações procedurais
originais deste projeto, sob MIT. Para regenerar: `python3 scripts/generate-demo-assets.py`.
As fotografias usadas na fase privada do protótipo foram substituídas; elas não são
redistribuídas no repositório público nem no seu histórico. Os resultados históricos
de benchmark anteriores à substituição continuam identificados por hashes/proveniência.
